### #6 詳細: QRスキャン画面のUX改修

| 小項目 | 内容 | 状態 |
|--------|------|------|
| **a. ガイド枠の表示** | カメラ中央に四角いスキャンガイド枠を描画し、QRコードをどこに合わせればいいか視覚的に示す | ✅ 実装済 |
| **b. どちらのQRを読むか案内** | 馬券には左右2つのQRがある。初回スキャン時に「左側のQRコードを読み取ってください」とテキスト＋図示で案内する | ✅ 実装済 |
| **c. 2QRスキャンの段階表示** | 1枚目読み取り後「右側のQRコードを読み取ってください」と案内を切り替え、プログレス（1/2 → 2/2）を表示する | ✅ 実装済 |
| **d. 1QRで完結する場合のスキップ** | 単純な馬券（単勝・複勝等）は左QRだけで情報が揃うため、自動で遷移。2QR目の案内は不要 | ✅ 実装済 |
| **e. スキャン状態の色分け** | 1枚目待ち=デフォルト、2枚目待ち=ガイド枠の色を変える等で状態を視覚的に区別する | ✅ 実装済 |
| 8 | 月別/年別の集計ビュー | Analysis | 日別トレンドはあるが月・年ごとの比較ビューがない | ✅ 実装済 |
