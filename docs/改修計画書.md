## #4 Toast通知の導入（P1）

### 現状
- RecordEdit: 保存成功/更新成功/削除成功で `Alert.alert()` を使用（計9箇所）
- Alert.alertはモーダルダイアログで操作が中断される

### 方針
新規パッケージ追加を避け、React Nativeの `ToastAndroid`（Android）と

もしくは `expo-toast`（軽量）を検討。

### 変更ファイル

| ファイル | 変更内容 |
|---------|---------|
| `src/components/common/Toast.tsx` | 新規：軽量Toastコンポーネント |
| `src/screens/RecordEdit.tsx` | 成功系Alert → Toast呼び出しに置換 |

### 実装内容

#### Toast.tsx（新規）

```typescript
import { useEffect } from 'react';
import { Animated, StyleSheet, Text } from 'react-native';

type Props = {
  message: string;
  visible: boolean;
  onHide: () => void;
  duration?: number;
};

export const Toast = ({ message, visible, onHide, duration = 2000 }: Props) => {
  const opacity = new Animated.Value(0);

  useEffect(() => {
    if (visible) {
      Animated.sequence([
        Animated.timing(opacity, { toValue: 1, duration: 200, useNativeDriver: true }),
        Animated.delay(duration),
        Animated.timing(opacity, { toValue: 0, duration: 200, useNativeDriver: true }),
      ]).start(() => onHide());
    }
  }, [visible]);

  if (!visible) return null;

  return (
    <Animated.View style={[styles.container, { opacity }]}>
      <Text style={styles.text}>{message}</Text>
    </Animated.View>
  );
};

const styles = StyleSheet.create({
  container: {
    position: 'absolute',
    bottom: 100,
    alignSelf: 'center',
    backgroundColor: 'rgba(0,0,0,0.8)',
    paddingHorizontal: 20,
    paddingVertical: 12,
    borderRadius: 24,
  },
  text: { color: '#fff', fontSize: 14 },
});
```

#### RecordEdit.tsx の置換対象

| 現状のAlert | 置換後 |
|------------|--------|
| `Alert.alert('登録完了', '収支を保存しました')` | Toast → `navigation.goBack()` |
| `Alert.alert('更新完了', '収支を更新しました')` | Toast → `navigation.goBack()` |
| `Alert.alert('削除完了', 'レコードを削除しました')` | Toast → `navigation.goBack()` |

※ 削除確認ダイアログも `Alert.alert` のまま維持（確認操作が必要）。

### 検証

### 実装内容

#### useMonthlyStats.ts（新規）

```typescript
type MonthlyRow = {
  month: string;        // "2026-01" 形式
  investment: number;
  return: number;
  profit: number;
  recoveryRate: number;
  betCount: number;     // 賭け回数
};

export const useMonthlyStats = (): MonthlyRow[] => {
  const [stats, setStats] = useState<MonthlyRow[]>([]);

  useFocusEffect(useCallback(() => {
    const load = async () => {
      const records = await getAllBetRecords();
      const map = new Map<string, { inv: number; ret: number; count: number }>();

      records.forEach((r) => {
        const month = r.date.toISOString().slice(0, 7); // "YYYY-MM"
        const cur = map.get(month) ?? { inv: 0, ret: 0, count: 0 };
        cur.inv += r.investment;
        cur.ret += r.return;
        cur.count += 1;
        map.set(month, cur);
      });

      const rows: MonthlyRow[] = [...map.entries()].map(([month, v]) => ({
        month,
        investment: v.inv,
        return: v.ret,
        profit: v.ret - v.inv,
        recoveryRate: v.inv > 0 ? Math.round((v.ret / v.inv) * 100) : 0,
        betCount: v.count,
      }));

      setStats(rows);
    };
    load();
  }, []));

  return stats;
};
```

import * as Sharing from 'expo-sharing';

export const exportAsCSV = async (records: BetRecord[]): Promise<void> => {
  const header = 'date,place,race_no,bet_type,investment,return\n';
  const rows = records.map(r =>
    `${r.date.toISOString()},${r.place},${r.race_no},${r.bet_type},${r.investment},${r.return}`

  const filePath = `${FileSystem.cacheDirectory}keiba_records.csv`;

};

import { Component, ReactNode } from 'react';
import { View, Text, TouchableOpacity, StyleSheet } from 'react-native';

type Props = { children: ReactNode };
type State = { hasError: boolean; error: Error | null };

export class ErrorBoundary extends Component<Props, State> {
  state: State = { hasError: false, error: null };

  static getDerivedStateFromError(error: Error) {
    return { hasError: true, error };
  }

  handleReset = () => {
    this.setState({ hasError: false, error: null });
  };

  render() {
    if (this.state.hasError) {
      return (
        <View style={styles.container}>
          <Text style={styles.title}>エラーが発生しました</Text>
          <Text style={styles.message}>
            アプリで予期しないエラーが発生しました。
          </Text>
          <TouchableOpacity style={styles.button} onPress={this.handleReset}>
            <Text style={styles.buttonText}>再試行</Text>
          </TouchableOpacity>
        </View>
      );
    }
    return this.props.children;
  }
}

const styles = StyleSheet.create({

## #15 QR読み取り時の日付反映（P0）

### 現状
- QRコードのbase部分に開催情報が含まれている:
  - `year`（7-8桁目）: 西暦下2桁（例: 26 → 2026年）
  - `kai`（9-10桁目）: 第N回開催
  - `day`（11-12桁目）: 開催N日目
- `qrExtractors.ts` で `year`, `kai`, `day` を抽出済み
- `qrTypes.ts` の `JRAQRData` にも `year`, `kai`, `day` フィールドあり
- しかし RecordEdit.tsx では QR由来のデータを受け取っても `date` は常に `new Date()`（今日）を設定
- ユーザーは馬券購入日ではなくスキャンした日が記録されてしまう

### 問題点
QRの `year` + `kai` + `day` は「2026年 第3回 8日目」のような開催情報であり、
**カレンダー日付そのものではない**。JRAの開催カレンダーと突き合わせないと正確な日付に変換できない。

ただし、QRのbase部分には他にも情報がある可能性がある。
また、地方競馬のQRでは日付フォーマットが異なる可能性もある。

### 方針

**段階A（即時対応・最小実装）**: QRデータに含まれる `year` を使い、開催年だけでも反映する。
`kai` と `day` からは正確なカレンダー日付を導出できないため、近似的なアプローチを取る。

**段階B（将来対応）**: JRA開催スケジュールのマスタデータを持ち、`year` + `kai` + `day` + `place` から
正確な開催日を逆引きする。

### 変更ファイル

| ファイル | 変更内容 |
|---------|---------|
| `src/services/qr/qrExtractors.ts` | 開催日推定関数を追加 |
| `src/services/qr/qrTypes.ts` | `JRAQRData` に `estimatedDate` フィールド追加 |
| `src/services/qr/qrScanner.ts` | 抽出時に `estimatedDate` を算出 |
| `src/screens/RecordEdit.tsx` | QRデータの `estimatedDate` があれば `date` に反映 |

### 実装内容

#### 段階A: 開催日の近似推定

JRAの開催は基本的に土日。`year` + `place` + `kai` + `day` から
「第N回○○競馬場のN日目」はおおよそ以下のように推定できる:

```typescript
// qrExtractors.ts に追加
/**
 * QRの開催情報から近似的な開催日を推定する。
 * 正確な日付はJRA開催カレンダーなしでは導出不可のため、
 * QRデータにカレンダー日付情報がある場合はそちらを優先。
 *
 * 現状は year のみ反映し、月日はスキャン日を使う妥協案。
 * 将来的に開催カレンダーマスタで正確に逆引きする。
 */
export const estimateRaceDate = (
  year: number | null,
): Date | null => {
  if (year === null) return null;
  // year は下2桁（例: 26）。2000年代を想定
  const fullYear = year < 50 ? 2000 + year : 1900 + year;
  // 年だけ反映し、月日は現在日付を使う
  const now = new Date();
  return new Date(fullYear, now.getMonth(), now.getDate());
};
```
